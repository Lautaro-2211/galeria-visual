# Mi Viaje

**Nombre y apellido:** Lautaro Peduto  
**Título tentativo de la galería:** Mi Viaje

**Tema elegido:** Fotografía de viaje — paisajes y ciudades de Europa

## Descripción de la propuesta

Esta galería reunirá fotos propias tomadas durante un viaje por España, Italia y Ámsterdam. El objetivo es mostrar, a través de imágenes de paisajes y ciudades, los lugares recorridos durante ese viaje.

## Objetivo de la galería

Compartir una selección de fotografías personales que reflejen la experiencia del viaje, destacando la arquitectura, los paisajes urbanos y naturales de cada destino visitado.

## Contenidos

La galería incluirá fotografías organizadas por destino:

- **España:** paisajes y vistas de ciudades
- **Italia:** paisajes y vistas de ciudades
- **Ámsterdam:** paisajes y vistas de la ciudad

## Decisiones de diseño

Para la hoja de estilos se utilizó una paleta de colores relacionada con el tema del viaje: un azul profundo (#1e3a5f) como color principal, que hace referencia el cielo y el mar, y un tono terracota (#c96f4a) como color de acento en los botones, aportando calidez. El fondo general es un beige suave (#f5f1e8), pensado para que las fotografías sean el centro de atención de cada página.

La tipografía elegida es una fuente sans-serif (Segoe UI / Arial), simple y legible, que no le resta protagonismo a las imágenes.

El sitio se organizó utilizando etiquetas semánticas de HTML (`header`, `main`, `section`, `footer`) y clases CSS reutilizables (como `.tarjeta` y `.galeria-fotos`) para mantener un diseño consistente entre la página principal y las páginas de cada destino.
